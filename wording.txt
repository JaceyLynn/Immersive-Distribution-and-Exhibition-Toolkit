# WORDING FILE: Immersive Distribution and Exhibition Toolkit
#
# This file holds the wording on the toolkit's screens. You can change it here without touching the code.
#
# HOW TO EDIT
#   Each line looks like this:
#       Text on the page now => Text you want to show instead
#   1. Find the line. Use Ctrl+F (Cmd+F on a Mac) to search for the words you see on the page.
#   2. Change ONLY the text after "=>". Leave the text before "=>" exactly as it is, or the page can't find it.
#   3. Keep each entry on one line.
#   4. To undo a change, make the text after "=>" the same as the text before it again.
#
# ADDING A NEW ITEM
#   Start a new line with + then the question (or Resources page) it belongs to, then "=>", then the new item:
#       + What venue type are you interested in? => Pop-up space
#       + Checklist => Insurance certificates
#       + Catalogues => Catalogue name | https://link-to-it.org | One-line description (optional)
#   - Works for answer options in any question, checklist items, and links on the Catalogues and Directories pages.
#   - Copy the question exactly as it appears in this file (the text before "=>" in its section).
#   - New Database options show as "no data yet" until venues in the Airtable are tagged with them.
#   - New questions and new filter types still need the development team.
#   - You can add your new lines anywhere, for example at the very end of this file.
#
# GOOD TO KNOW
#   - Lines that start with # are notes. The page ignores them.
#   - If the same text appears in several places (for example an option used in two sections), one change updates it everywhere.
#   - Some text that mixes in a number (like "325 matching entries") isn't listed, because it changes as people use the page.
#   - Venue and festival details come from the Airtable data, and the case study texts quote the IDFA report, so neither is in this file.
#   - After you save ("Commit changes"), the live site updates within a few minutes. Refresh the page to see it.
#   - If something looks wrong, undo your change in this file. The page always falls back to its built-in wording.
